# PhEW-model
A standalone version of the PhEW model (Huang et al. 2020) written in python. It models the cloud-crushing problem of a cool cloud moving through a uniform hot gas. For simplicity, the core of the cloud is always assumed to be at a temperature of 10^4 K.

The cooling tables are calculated by Wiersma et al. (2009) and downloaded from this website: https://local.strw.leidenuniv.nl/WSS08/
